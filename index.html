精度控制

Quick Start

使用指南

安装即用，三种调用方式随你选

安装

bash
npm install @sprit/anf

基础用法

TypeScriptexample.ts
import autoNumberFormat, { AutoNumberFormat } from '@sprit/anf'; // 1. 类方式 new AutoNumberFormat('123456789').format({ calcStrategy: 'en_US', suffixUpperCase: true }); // → '123.46M' // 2. 函数方式 autoNumberFormat({ calcStrategy: 'zh_CN' }, '123456'); // → '12.35万' // 3. 柯里化（缺参数返回预置函数，齐了出结果） const fmt = autoNumberFormat({ calcStrategy: 'zh_CN' }); fmt('540453'); // → '54.05万'
💡
函数式调用自动判断参数完整度—缺参数就返回预置函数，齐了就出结果。

📖 快速概览

anf.js (Auto Number Format) 是一个轻量级、零依赖的 JavaScript 数值格式化库。提供中英文等多套计算策略，支持精度控制、千分位分隔、科学计数法展开等丰富的格式化功能。

💡
这是 anf.js 的文档测试页面，代码逻辑基于 fantian007/anf 项目，交互演示可直接试用全部参数。

核心设计

  • 零依赖 — 纯 JS 实现，无任何外部运行时依赖，压缩后约 4KB
  • 策略模式 — 计算策略与输出格式分离，自由组合
  • 智能柯里化 — 函数式调用自动判断参数完整度
  • 三种调用方式 — class / function / curry，即用即走
  • TypeScript 友好 — 完整的类型定义文件
